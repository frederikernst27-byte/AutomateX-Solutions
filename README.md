# AutomateX Solutions

Dieses Repository ist nach Arbeitsbereichen sortiert:

- `public/` - deploybare Website fuer Vercel, inklusive HTML-Seiten und Brand-Assets
- `assets/` - Dokumente, Audio-Dateien und Archive
- `docs/` - Architektur, Setup, Tests und Planungsunterlagen
- `examples/` - Beispieldaten
- `prototypes/` - Prototypen und Demos
- `clients/` - kundenbezogene Arbeitsdateien
- `tasks/` - aktuelle Aufgaben und operative Notizen
- `sync/` - synchronisierte oder importierte Projektkopien
- `tools/` - lokale Hilfsskripte
- `logs/` - lokale Logdateien

## Deployment

Die Website liegt in `public/` und wird ueber Vercel deployt. Die Konfiguration steht in `vercel.json`.

Production-Alias:

```text
https://automatex-six.vercel.app
```
