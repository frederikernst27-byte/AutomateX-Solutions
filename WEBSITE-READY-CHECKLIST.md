# AutomateX Website – Ready-for-Production Checklist

## Rechtliches (Pflicht)
- [ ] `impressum.html` vollständig mit echter Anschrift ausgefüllt
- [ ] `datenschutz.html` auf echten Tool-Stack abgestimmt
- [ ] Footer-Links auf Impressum/Datenschutz getestet
- [ ] Kontaktformular-Hinweis + Zweckbindung klar

## Kontakt & Leads
- [ ] FormSubmit funktioniert auf Live-Domain (nicht file://)
- [ ] Testanfrage gesendet und empfangen
- [ ] Antwortprozess definiert (SLA < 2h werktags)
- [ ] CRM/Notion Pipeline für neue Leads eingerichtet

## Technik
- [ ] HTTPS aktiv
- [ ] Vercel Deployment erfolgreich
- [ ] Keine kaputten Zeichen/Encoding-Fehler
- [ ] Mobile Darstellung geprüft (iPhone + Android Breiten)
- [ ] Ladezeit geprüft (Hero + Bilder optimiert)

## Vertrauen / Conversion
- [ ] Klare Hero Value Proposition
- [ ] Social Proof sichtbar (Referenzen/Cases)
- [ ] CTA in allen Kernsektionen
- [ ] Referenzpreise + Hinweis auf individuelle Kalkulation

## SEO Basics
- [ ] Titel und Description sinnvoll
- [ ] Nur eine H1 pro Seite
- [ ] Saubere interne Links
- [ ] Favicon und OpenGraph-Bilder ergänzen (optional)

## Vor Livegang
- [ ] Letzter End-to-End Test (Desktop/Mobile)
- [ ] Kontaktformular + Mail-Links getestet
- [ ] Rechtstexte final gegengeprüft
- [ ] Deployment auf Prod bestätigt
