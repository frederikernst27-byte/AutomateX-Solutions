# **App Name**: AutomateX Solutions

## Core Features:

- Home Page Showcase: Displays an engaging overview of AutomateX, highlighting the simplification of business workflows through automation, with a clear call-to-action for booking a demo or consultation.
- Automations Example Display: Interactive section showcasing n8n automation examples like TalentMatch (recruiting process integration), Deal-Benachrichtigungen (daily deal email), Angebotsanfragen (automated quotes), and Lead-Qualifizierung (lead scoring).
- Service Details: Detailed service descriptions for ERP integration, custom n8n automation solutions, and API integrations.
- Contact Form: Direct inquiry submissions for n8n-based automation solutions.
- AI Workflow Recommendations: A generative AI tool that suggests tailored n8n workflow automation ideas based on the user's industry and operational needs.
- Workflow Visualization: Display n8n workflows as diagrams with interactive elements.
- Blog Integration: Publish tutorials on n8n, automation tips, and client success stories, automatically formatting them with Next.js and linking relevant content within the site.

## Style Guidelines:

- Primary color: Dark blue (#224292) to convey trust and reliability.
- Background color: Very light grey (#F0F2F5) to maintain a professional and clean look.
- Accent color: Electric Purple (#8434D2) for highlighting interactive elements and calls to action.
- Headline font: 'Space Grotesk' sans-serif for a techy, modern look.
- Body font: 'Inter' sans-serif, paired with Space Grotesk for longer text blocks to ensure readability and a clean, modern feel.
- Use minimalistic icons representing different automation processes and services.
- Responsive and clean layout with a focus on white space to highlight content.
- Subtle transitions and animations to enhance user experience without being distracting.
